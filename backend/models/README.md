# PRAMAANX Model Weights Directory

This directory stores trained ML model weights for PRAMAANX:
- `tamper_effb0.pt`: Fine-tuned EfficientNet-B0 model for image tampering and ELA detection (trained in Phase 3).
- `malpdf_xgb.json`: Trained XGBoost classifier model for malicious PDF structural detection (trained in Phase 3).

## STRICT POLICY:
- Per project rules, **NO FAKE OR PLACEHOLDER WEIGHTS** are placed in this directory.
- Model weights will be trained on authentic datasets (e.g. CASIA v2.0 for image tampering and real PDF exploit corpora) using Kaggle GPU resources and placed here once verified.
